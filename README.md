# Urna do Quintal das Véias

Simulador de urna eletrônica para a eleição de presidente do Quintal das Véias,
o quintal onde a família se reúne aos domingos.

Abra o `index.html` no navegador do aparelho que vai servir de urna.

## Como usar

- **Votar:** digite o número da candidata e aperte **CONFIRMA**. **CORRIGE** apaga e **BRANCO** vota em branco.
  Um número que não existe vira voto nulo.
- **Área do mesário:** botão abaixo da urna, senha `1234`. Mostra o boletim de urna,
  permite trocar nome, número, partido e foto das candidatas e zerar os votos.
- Os votos ficam guardados só no navegador do aparelho usado como urna.
